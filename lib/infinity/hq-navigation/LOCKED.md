# HQ navigation integrity

VISIBLE HQ PRIMARY NAV ITEMS MUST NOT ACCIDENTALLY SHARE THE SAME DESTINATION.

One visible navigation purpose → one clear destination.

Intentional aliases are forbidden unless explicitly marked `allowedAlias` with a written justification. Default: duplicate href is FAIL.

React keys are the stable semantic `id`. Index-based keys are forbidden.

Placeholders have `href: null` and are not links.
